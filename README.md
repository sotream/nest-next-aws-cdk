# nest-next-aws-cdk

AWS CDK (TypeScript) deployment of [nest-next-starter](https://github.com/sotream/nest-next-starter) on ECS Fargate, with a preview environment per pull request. The CDK counterpart of [nest-next-aws-terraform](https://github.com/sotream/nest-next-aws-terraform).

Status: specification only. Read [docs/spec.md](docs/spec.md). Implementation proceeds feature by feature (spec section 9).
